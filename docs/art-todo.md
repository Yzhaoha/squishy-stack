# 捏捏叠叠乐 — 待画清单（照着复制粘贴就行）

在 ChatGPT 的 **「Generate Capybara Image」** 那个对话里，从上到下一条一条发。每个灰框是一条完整消息，点右上角的复制按钮，粘贴发送。

- 出图后下载 PNG，**文件名改成标题里的 id**（比如 `cow.png`）。
- 透明背景、横图 1536×1024。如果出来的图有背景或阴影，回一句：`Transparent background, no shadow, no ground.`
- 风格跑偏了（变扁平、变写实、脸不一样）就回一句：`Match the capybara exactly: same glossy squishy look, same bead eyes and blush.`
- 不用等全画完，画好几只就可以发给我，我分批接进游戏。

> **11-20 更新**：风格已改成「更粉嫩可爱」（粉彩暖粉色调、腮红更大更粉、眼睛更大带白色星星高光、身体更圆更胖）。下面灰框里的开头要换成新风格那句，颜色调成粉彩。
> 萌宠系列 11 只已按新风格画完。**水豚 capy、饺子 dump、六角恐龙 axo 是旧风格，需要按新风格重画。**
